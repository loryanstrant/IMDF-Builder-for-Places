Help

Quick Start:

  1. Enter your project name and building info
  2. Upload a floor plan image or PDF (multi-page PDFs can become one level per page)
  3. Set the venue coordinates, then calibrate the scale and set the anchor point
  4. Add at least one level
  5. Use the tools to place units, amenities, and other items
  6. Configure properties for each item
  7. Export IMDF files

Canvas controls:

  • ALT + drag — pan the floor plan
  • Mouse wheel — zoom in and out at the cursor
  • DEL — delete the selected item
  • ESC — cancel the polygon being drawn

If items land imprecisely, turn off Edge snapping.

Rooms do not have to be rectangles — use Draw Unit (Polygon) for L-shaped spaces, then drag the orange vertex dots to reshape them.

See docs/USAGE.md for best practices.
